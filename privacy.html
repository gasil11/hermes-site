This Privacy Policy describes how the Hermes Agent application ("the Application"), operated personally by Gökhan Asil ("the Owner"), handles information obtained through Google APIs.

1. Scope

The Application is a private, single-user tool. The only Google account it is authorised to access is the Owner's own account. No other person can use the Application or sign in to it.

2. Information accessed

With the Owner's explicit consent, the Application may access the following data belonging to the Owner's own Google account:

  • Gmail — message headers, senders, subjects, dates and message bodies, used to produce a daily summary and to identify messages requiring attention
  • Google Calendar — event titles, times, attendees and descriptions, used to display the Owner's schedule and to create events on the Owner's behalf
  • Google Sheets — spreadsheet contents used to store the Owner's own records

3. How the information is used

Information is used exclusively to provide the Owner with personal productivity functions requested by the Owner. The Application does not use this information for advertising, profiling, credit assessment or any purpose unrelated to those functions.

4. Storage and security

Data is processed and stored on the Owner's own privately hosted server. OAuth credentials are stored in a restricted file on that server and are never transmitted to any third party. The Application communicates with Google APIs over TLS.

5. Sharing and disclosure

No Google user data is sold, rented, traded or otherwise transferred to any third party. Data is not disclosed to third parties except where strictly required by law.

6. AI processing

To generate summaries, message content may be sent to the language-model provider configured by the Owner for that purpose. It is not used to train generalised or foundation models, and it is not made available to other users of any service.

7. Google API Limited Use disclosure

The Application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Retention and deletion

Summaries and derived notes are retained only as long as the Owner finds them useful and can be deleted by the Owner at any time. The Owner may revoke the Application's access at any time at myaccount.google.com/permissions, after which no further data is accessed.

9. Children

The Application is not directed at children and is not made available to any user other than the Owner.

10. Changes

Any change to this policy will be published on this page with an updated revision date.
